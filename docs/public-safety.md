# 공개 안전성 검토

이 저장소는 식단 이미지 기반 위험 신호와 보험 보장 항목 매칭 PoC의 공개 가능한 부분만 정리합니다. 평가 대상은 음식 탐지, 영양 패턴 집계, 위험 신호와 보장 항목 연결의 설계 방식입니다.

| 공개 | 제외 |
| --- | --- |
| 문제 정의, 모델링 흐름, 추천 규칙, 실제 발표 자료 기반 산출물 | 개인 식단 원본, 의료·개인정보, 원본 건강 데이터, 보험 원문, 대용량 학습 데이터 |

위험 신호는 의료 진단·보험 심사·보험료 산정의 근거가 아니며, 추천은 실제 보험 자문이나 판매가 아닙니다. 자세한 데이터 경계는 `docs/data.md`를 확인합니다.
