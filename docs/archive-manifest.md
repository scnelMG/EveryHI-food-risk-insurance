# 아카이브 제외 기준

`archive/`는 원본 보존을 위한 로컬 경로이며, 공개 GitHub 저장소에는 포함하지 않습니다. 이 문서는 무엇을 제외했는지 설명하는 목록일 뿐, 아카이브 파일을 공개하거나 배포한다는 의미가 아닙니다.

| 경로 | 제외 이유 |
| --- | --- |
| `archive/raw-data/` | 음식 이미지·라벨·국민건강영양조사 원자료 등 대용량 원천 데이터 |
| `archive/large-source/` | 대용량 zip, SAS 원본, 중복 압축 자료 |
| `archive/drafts-and-private/` | 사업계획서 초안, 참가신청서, 팀 내부 문서 |
| `archive/legacy-projects/` | 최종 발표 자료와 직접 관련 없는 별도 프로젝트 |
| `archive/unrelated/` | EveryHI와 무관한 조사 자료 |
| `archive/duplicates/` | 중복 이미지, 스크립트, 이전 실험 파일 |
| `archive/references/` | 공개 저장소에 직접 넣지 않는 참고 원문·지침 |

공개 저장소에는 README, 검토 문서, 공개 검토용 노트북, 실제 최종 발표 자료의 선별 이미지와 대표 결과만 남깁니다.
